# Java Churn Analyzer API 📊

API desenvolvida em Java focada em inteligência de negócios e análise de dados para identificação de evasão de clientes (Churn).

## 🚀 Funcionalidades
- Processamento e contagem de registros de clientes ativos e inativos.
- Cálculo preciso da taxa de Churn em formato percentual.
- Sistema de alertas automáticos para tomadas de decisão estratégica baseadas nos resultados.

## 🛠️ Tecnologias Utilizadas
- Java SE (Standard Edition)
- Lógica de Programação Orientada a Objetos
- Estruturas Condicionais e Controle de Fluxo

## 📈 Impacto de Negócio
Este projeto simula cenários reais enfrentados por grandes instituições financeiras e empresas de varejo, onde a análise de dados brutos é convertida em insights estratégicos para a retenção de usuários e saúde financeira do negócio.
